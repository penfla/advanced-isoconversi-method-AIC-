ⓘ User guide — v3.10.0

This application derives the effective activation energy Eα(α) of thermoset curing from non-isothermal DSC scans recorded at several heating rates β, using Vyazovkin's advanced isoconversional method (AIC), and turns it into a model-free prediction of the isothermal cure time.

1 · Quick start

  1. Press 📂 Real Files in the sidebar.
  2. + Add scans and select at least 3 files (4 or more recommended), one per heating rate.
  3. Check the β values detected automatically in the file list; enter the mass (mg) if you want the enthalpy normalised in J g⁻¹.
  4. The calculation starts on its own once loading completes (Auto-calculate checkbox). Otherwise press ▶ RUN VYAZOVKIN.
  5. Read the report, then export with ⬇ CSV, ⬇ Full report or ⎙ Print / PDF.

To try the app without data: ⚙ Simulation mode builds four synthetic DGEBA/IPDA thermograms from the kinetic parameters in the sidebar.

2 · Preparing the files

One file = one heating rate β. Accepted formats: .txt .csv .tsv .dat .asc .prn .json .xlsx .xls. Separator (comma, semicolon, tab, space) and decimal mark (point or comma) are detected automatically; a header row is optional.

A temperature column is required, plus either a conversion α column or a heat flow column. A time column is recommended: if missing it is reconstructed from β. Columns are identified from units ([s] [min] [mW] [°C] [K]), from names (time, t, Tr, temperature, alpha, conv, heat flow, DSC…) or, failing both, from the numeric behaviour of each column.

On the raw data the app automatically performs:

  • ramp extraction: in multi-segment files (heat/cool/heat) it isolates the first heating ramp and discards the instrument transients at both ends;
  • peak detection by local prominence, including the exothermic direction (exo-up / exo-down);
  • linear onset→endset baseline and peak integration to obtain α(t);
  • β from a least-squares fit of T vs t (with no time axis: from the file name, e.g. …10C_min…) and mass from the file name when present (e.g. … 11.3300 mg).

Every derived value is shown under the file name and stays editable by hand.

3 · Parameters

Δαisoconversional step (0.02–0.10). Smaller = more points, noisier at very low and very high conversion. Default 0.05.
Isothermal T min / maxtemperature range of the isothermal prediction (Iso-Conversion panel and its table).
β, m (mg)per scan: heating rate and sample mass. The mass is only used for the normalized value in J g⁻¹.
Simulation blockΔH, temperature range, four β values, Ea,chem, Ea,diff, αgel, autocatalytic exponent: active in Simulation mode only.

4 · Views and toolbar

The toolbar at the top of the results holds the two views and every export button:

  • ▤ MFK Report — the four-panel STARe sheet (thermograms, conversion, activation energy, iso-conversion).
  • 📈 Charts & Tables — the remaining charts (DSC vs T, α vs T, Vyazovkin vs KAS, Φ function), the per-scan raw data and the result tables.
  • 🔬 Manual DSC — one trace at a time, with the tools to place the integration limits by hand (see §6).
  • ⎙ Export PDF, ⬇ Full report (HTML), ⬇ CSV / TSV / Isothermal CSV, ⎘ Copy — always reachable, the toolbar stays pinned while scrolling.
  • img selector — resolution of the exported chart images (1× screen … 4× print). Use 3×–4× when the PDF is meant for print.

5 · Reading the report

Thermograms
(top left)		heat flow vs time, one curve per β. Alongside: Integral (mJ), normalized (J g⁻¹, needs the mass), Peak (°C). The ↑ exo marker gives the exothermic direction.
Conversion
(top right)		α % vs temperature. The curves must be ordered and never cross: a higher β shifts the curve to the right. Alongside, the °C / % table for each scan.
Activation Energy
(bottom left)		Eα vs conversion with a ±σ band. A flat trend means a single-step process; a rise at high conversion means the reaction has moved to diffusion control after gelation.
Iso-Conversion
(bottom right)		predicted time to reach a given α while holding the sample at constant temperature. Logarithmic vertical scale. The α chips above the plot choose which curves are shown; shortcuts all, none, α = 0.1 … 0.9.

6 · Manual adjustments

  • Peak picker: when no peak stands out from the baseline noise, the scan is not discarded — its raw trace is plotted in a dedicated panel so you can read the onset and endset temperatures off the curve and type them in. Apply re-integrates and rejoins the scan to the analysis, Try auto goes back to automatic detection. The tabs switch between the scans still waiting for a manual peak.
  • Integration limits (box below the thermograms): for each ramp you can force the start and end temperature of the peak integration. A blank field means the automatic limit (detected onset/endset). all automatic restores automatic detection on every scan. Any change recomputes α, Eα and the isothermal prediction.
  • Manual DSC view (🔬 in the toolbar): pick any scan from the tabs and inspect its raw trace full-width. whole file plots the run exactly as recorded — every step, heating, cooling and isothermal holds included — with the segment feeding the analysis drawn in bold; analysis segment narrows the plot to that segment alone. Under the toolbar, one chip per step (↗ heat, ↘ cool, → hold, with range, rate and duration in the tooltip) switches the analysis onto that step, and use whole file analyses the run without splitting it. β is re-estimated on the new window. If you type limits that fall in another step while looking at the whole file, the analysis moves onto that step by itself. Controls: x switches between temperature and time; y switches between raw heat flow, baseline-subtracted (a straight baseline is removed, so a peak worth only a few tenths of a mW at very low β becomes obvious) and derivative (the peak sits where it crosses zero); whole trace / zoom on window toggles the view. Type the limits, choose °C or min, then Apply limits. detect in window re-runs the automatic onset/endset search restricted to the current window — the usual fix when a shallow peak is missed globally. back to auto restores automatic detection. The read-out below the chart reports state, window, integral, normalized enthalpy, peak temperature and β.
  • Integration limits in °C or minutes: each scan carries its own unit; switching it converts the values already entered so the integrated window does not move.
  • Enabling scans: the checkbox on each row of Loaded Files includes or excludes that scan from the analysis without removing the file. all / none act on every row; the counter shows how many scans are active. The analysis re-runs on each change and needs at least 3 active scans.
  • First report panel: x = time / x = temperature switches the abscissa of the integrated thermograms.
  • Axes: the axes strip under each chart sets x min/max and y min/max. A blank field means autoscale; ⟲ auto clears the limits of that chart. The grey values in the fields are the bounds currently computed by the app.

7 · Quality checks

  • Vyazovkin vs KAS: the two methods must agree closely. Large gaps point to badly built α curves (wrong baseline or wrong segment).
  • Φ(Eα): it must show a sharp minimum inside the search range. If the minimum sits on a bound, the point is flagged ⚠ in the table and in the status bar: that Eα is not reliable, usually because the Tα values of the different β are not separated.
  • ±σ in the table is the spread of the pairwise isoconversional estimates: large values at the extremes of α are normal.

8 · Sessions

A session stores everything: loaded scans with their raw data, β, masses, integration limits, analysis parameters, axis ranges and α selection.

  • 💾 Save session writes a .pfvyaz file. On Chrome and Edge a dialog lets you choose the destination folder and file name; on other browsers the file goes to the download folder.
  • 📁 Open session restores it and re-runs the calculation.
  • 🗑 New session clears loaded scans, results, charts, axis ranges and α selection, asking for confirmation when there are unsaved changes.
  • A red ● unsaved marker appears in the header as soon as anything changes (files added or removed, β, mass, integration limits). Closing or reloading the tab in that state triggers the browser's «leave site?» confirmation, so a session is never lost by accident. Saving or opening a session clears the marker.

A .pfvyaz file is UTF-8 JSON, so it can also be read by other tools; numeric series are rounded to 6 significant digits to keep the file small.

9 · Exporting

  • ⬇ CSV / TSV / ⎘ Copy: Eα(α) table with Tα for each β, σ, KAS and phase.
  • ⬇ Isothermal CSV: predicted times (minutes) for every α and every temperature.
  • ⬇ Full report: one self-contained HTML file with every chart as a PNG, the annotations, the Eα(α) and isothermal-time tables and the CSVs embedded.
  • ⎙ Export PDF: prints the four MFK panels on a single A4-landscape page (further charts and tables follow on the next pages); date and page number are placed top-right. Turn off the browser's own header/footer in the print dialog for a clean sheet.

CSV files use ASCII headers (alpha, Ea_kJmol) for import into Excel/Origin.

10 · Troubleshooting

«Load at least 3 DSC scans»at least 3 files with different β are required.
«temperature column not identified»add a header carrying the units, e.g. t [s] · T [°C] · Heat Flow [mW].
«no peak stands out from the baseline noise»the scan stays loaded: set the limits in the Peak picker panel. If the file really holds no reaction (e.g. only the second heating, Tg scan), use the first heating instead.
wrong βedit it by hand in the file list: the calculation updates.
peak integrated badlyset manual limits in the Peak integration box under the thermograms, or open 🔬 Manual DSC for the full toolset.
very low β, peak almost flatopen 🔬 Manual DSC, switch y to baseline-subtracted, bracket the bump with the limits and press detect in window.
the peak is in another stepin 🔬 Manual DSC keep whole file on and click the step chip that holds the exotherm (a second heating, for instance), or type limits inside it — the analysis follows.
Eα flagged ⚠ or absurdcheck that the conversion curves are separated between the different β and that the extracted ramp (shown under the file name) is the curing one.
normalized shows «—»the sample mass is missing: fill the m (mg) field.

11 · Method

For each α the following is minimised with respect to Eα:

Φ(Eα) = Σᵢ Σⱼ≠ᵢ  J[Eα, Tᵢ(tα)] / J[Eα, Tⱼ(tα)]

J[Eα, Tᵢ] = ∫  exp(−Eα / R·T(t)) dt     over [t(α−Δα), t(α)]

J is evaluated with the trapezoidal rule on an interpolated α grid (40 points per interval) and the minimum is found by Golden Section Search. Isothermal prediction:

t_α(T₀) = [ ∫₀^{T_α} exp(−E_α/RT) dT ] / [ β · exp(−E_α/R·T₀) ]

with Tα and β taken from the reference scan (lowest β). Model-free: no assumption on the form of f(α). Minimum 3 ramps, 4 or more recommended (ICTAC 2011).
